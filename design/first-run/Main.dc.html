Edit a saved colony

Duplicity opens an Oxygen Not Included save file, lets you change what is inside it, and writes a new one back out. Everything happens in this browser tab — the save is never uploaded anywhere.

Back up the save first. Duplicity can write a file the game refuses to load, and a clean load here is no proof the game will accept the result.

Duplicants, geysers, creatures, asteroids and stored materials each get a page in the sidebar. They stay locked until a save is open, and the Overview then says what this colony actually has.

Save, then move the file back
Save downloads a new .sav named after the colony — it does not write over the original. Put that file in save_files in place of the copy you backed up, then load the colony in game.

Reads and writes base game and Spaced Out! saves, including the Frosty Planet, Bionic Booster, Prehistoric Planet and Aquatic Planet packs. Save versions 7.28 through 7.38; a newer save loads only behind an explicit override.
